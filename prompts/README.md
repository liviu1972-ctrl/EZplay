# Prompturi reutilizabile

Aici pot fi păstrate prompturi testate pentru sarcini repetitive EZPLAY.

Un prompt trebuie să precizeze:

- scopul;
- contextul necesar;
- fișierele care trebuie citite;
- rezultatul așteptat;
- limitele și verificările.

Nu salva conversații întregi sau prompturi neverificate doar pentru arhivă.
