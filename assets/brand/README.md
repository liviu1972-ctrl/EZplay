# Identitate de brand EZPLAY

În prezent, identitatea versionată pornește de la sigla principală `EZPLAY`, importată din activul runtime existent `public/logo_ezplay.svg`.

## Sigla primară

- master vectorial: `logo/approved-master/ezplay-logo-primary-v01-approved-master.svg`;
- derivate WebP transparente: `logo/public/`, la lățimi de `256`, `512` și `1024` px;
- WebP-ul nu conține fundal și poate fi așezat pe fundalurile site-ului fără o placă albă.

SVG-ul este masterul disponibil în acest moment. Dacă apare fișierul CorelDRAW original, acesta se adaugă în `logo/source/`, fără a înlocui sau redenumi retroactiv masterul curent.
