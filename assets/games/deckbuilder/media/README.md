# Media Deckbuilder

Acest director păstrează media asociată jocului, fără a o transforma automat în conținut runtime sau public:

- `tutorials/review/` conține exporturi video care trebuie văzute și aprobate înainte de publicare;
- `promo/review/` conține imagini de lucru, inclusiv exporturi generate, care au nevoie de un scop editorial înainte de a deveni mastere sau derivate publice.

Fișierele din `review/` sunt organizate și inventariate, dar nu sunt promisiuni de publicare. Un export pentru web, thumbnail sau montaj nou se creează numai după alegerea canalului și a mesajului.
