# Documentație legacy a aplicației

Acest director păstrează, fără rescriere, trei grupuri de documente din versiuni anterioare:

- `application/` — funcții, roluri și comportamente descrise înaintea reconstrucției curente;
- `ezplay/` — materiale despre joc și o arhitectură Firebase/Vite mai veche;
- `technical/` — arhitectură, autentificare, baze de date, API și deployment nevalidate pentru aplicația Next.js/Supabase curentă.

Aceste documente au valoare istorică, nu autoritate tehnică actuală. Refacerea documentației tehnice se va face separat, pornind din codul verificat.
