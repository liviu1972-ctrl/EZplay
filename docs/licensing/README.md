# Licențiere și protecție

Aici vor fi documentate separat:

- jocurile și materialele deschise;
- permisiunea de facilitare comunitară;
- brandul și marca EZPLAY;
- utilizarea comercială;
- eventual regimul codului platformei.

Direcția de lucru este:

> **Open Core, Protected Program, Trusted Community**

Documentele juridice nu există încă în acest workspace. Nu formula texte ca fiind validate juridic fără revizuire specializată.

Aceste registre pregătesc publicarea și revizuirea juridică. Ele nu sunt licențe, acorduri, termeni de utilizare, politici de confidențialitate sau formulare de consimțământ.
