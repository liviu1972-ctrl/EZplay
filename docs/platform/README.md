# Platforma ezplay.org

Aici este documentată platforma ca produs, separat conceptual de implementarea din `src/`, dar în același repository.

Pot fi documentate:

- utilizatorii prioritari;
- jobs-to-be-done;
- parcursurile;
- rolurile și accesul;
- jocul, învățarea și contribuția;
- cerințele funcționale;
- arhitectura de produs;
- relația cu experiențele offline.

Platforma nu trebuie definită numai prin funcțiile construite. Implementarea curentă se evaluează în raport cu experiența aprobată și se verifică direct în cod.
