# Programul educațional EZPLAY

Aici va fi documentat produsul educațional care transformă jocurile în experiențe intenționate de învățare.

Poate include:

- public și obiective;
- formate de sesiune;
- parcursuri;
- materiale pentru facilitatori;
- module tematice;
- evaluare și Level Up.

În prezent, metoda nu este complet standardizată. Nu prezenta programul ca produs finalizat.

Detaliile existente se găsesc momentan în `docs/roadmap/current-assets.md` și vor fi extrase aici doar printr-o migrare aprobată.
