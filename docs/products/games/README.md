# Jocurile EZPLAY

Aici se documentează fiecare joc ca produs distinct.

În prezent sunt rezervate:

- [`deckbuilder/`](deckbuilder/) — **EZPLAY Deckbuilder**, jocul de bază, fizic și digital;
- [`tableau-builder/`](tableau-builder/) — **EZPLAY Tableau Builder**, jocul avansat, încă la nivel de concept și prototipare.

Formele scurte `Deckbuilder` și `Tableau Builder` pot fi folosite după prima mențiune. `EZPLAY1` și `EZPLAY2` sunt numai aliasuri istorice pentru interpretarea prompturilor și nu sunt nume de produs.

Modelul economic comun nu se redefinește aici. Sursa canonică este `docs/methods/economic-model.md`.
