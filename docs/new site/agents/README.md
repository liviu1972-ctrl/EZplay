# Agenți specializați

Aici pot fi documentați agenți AI cu responsabilități restrânse, de exemplu pentru reguli, playtest-uri, conținut sau audit de terminologie.

Fiecare agent trebuie să definească:

- rolul;
- sursele canonice;
- ce poate modifica;
- ce necesită aprobare;
- formatul rezultatului;
- verificările obligatorii.

`AGENTS.md` de la rădăcină rămâne setul general de instrucțiuni pentru întregul repository.
