# Website și platformă

Acest folder descrie zona logică a aplicației principale `ezplay.org`. Nu conține automat sursele aplicației și nu dovedește existența unei aplicații separate.

Codul Next.js curent este dezvoltat în repository-ul tehnic separat și poate fi importat aici numai în urma unei decizii explicite.

Poate include:

- homepage și pagini publice;
- autentificare și profiluri;
- Card Browser și regulamente;
- jocuri integrate;
- administrare;
- progres și comunitate;
- integrarea cu Supabase și Vercel.

Aplicația existentă din repository-ul tehnic este un prototip. Nu presupune că structura sa trebuie păstrată integral și nu propune rescrierea înainte de clarificarea fluxurilor principale.

Deckbuilder-ul și simulatorul sunt integrate în aceeași aplicație curentă. Folderele lor de la nivelul `apps/` descriu responsabilități logice și nu impun servicii sau repository-uri separate.
