# Aplicația Deckbuilder

Acest folder descrie zona logică și contextul tehnic al jocului digital EZPLAY Deckbuilder. Existența sa nu dovedește că Deckbuilder-ul este o aplicație separată.

Codul curent este integrat în aplicația Next.js `ezplay.org` și este dezvoltat în repository-ul tehnic separat. Nu îl copia aici fără o decizie explicită.

O separare viitoare într-o aplicație proprie se justifică numai dacă apar nevoi precum:

- build și deploy independent;
- multiplayer sau runtime separat;
- reutilizarea jocului în mai multe produse;
- limite tehnice clare ale aplicației principale.

Nu copia codul jocului aici doar pentru a umple structura.
