# Simulator și experimente automate

Acest folder descrie zona logică pentru simulări, testarea echilibrului și experimentele cu jucători controlați de sistem. Existența lui nu dovedește existența unei aplicații separate.

Codul simulatorului curent este integrat în aplicația Next.js `ezplay.org` și este dezvoltat în repository-ul tehnic separat. Importarea lui aici necesită o decizie explicită.

Poate conține ulterior:

- rulări automate de partide;
- strategii rule-based;
- validarea configurațiilor;
- analize de echilibru;
- instrumente interne de game design;
- experimente AI aprobate.

Simulatorul existent este insuficient validat. Nu folosi rezultatele lui ca adevăr până când formulele și stările jocului nu sunt verificate.

Separarea simulatorului se justifică numai dacă produce un beneficiu real și este aprobată după inspectarea structurii tehnice existente.
