# Aplicațiile EZPLAY

Aceste directoare descriu zone logice de produs și contextul lor tehnic. Existența folderelor nu dovedește existența unor aplicații sau servicii separate.

- `website/` — site-ul, conturile și experiența generală de pe ezplay.org;
- `deckbuilder/` — jocul digital;
- `simulator/` — simulări, testare automată și experimente cu jucători controlați de sistem.

Codul curent al `ezplay.org`, Deckbuilder-ului digital și simulatorului integrat este dezvoltat într-un repository tehnic separat. Nu îl copia și nu îl importa aici fără o decizie explicită.

Dacă va fi aprobat ulterior un import, inspectează mai întâi structura tehnică existentă și documentează dependențele dintre zone. Separarea codului se justifică numai prin nevoi reale ale produsului și implementării.
