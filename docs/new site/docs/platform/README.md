# Platforma ezplay.org

Aici va fi documentată platforma ca produs, separat de codul din `apps/`.

Pot fi documentate:

- utilizatorii prioritari;
- jobs-to-be-done;
- parcursurile;
- rolurile și accesul;
- jocul, învățarea și contribuția;
- cerințele funcționale;
- arhitectura de produs;
- relația cu experiențele offline.

Platforma nu trebuie definită prin funcțiile deja construite. Aplicația actuală este un prototip și trebuie evaluată în raport cu experiența dorită.
