# Documentația EZPLAY

`docs/` conține documentația vie a proiectului.

Zonele sunt separate după rol:

- `context/` — identitate, poziționare și viziune;
- `methods/` — modele și metode comune;
- `products/` — produsele și experiențele;
- `platform/` — produsul digital ezplay.org;
- `community/` — participare și guvernanță;
- `roadmap/` — realitatea curentă și prioritățile;
- `decisions/` — decizii importante și motivele lor.

Nu dubla definițiile canonice între directoare. Un document de produs explică aplicarea unui model, nu îl redefinește.
