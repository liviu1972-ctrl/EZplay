# Comunitatea EZPLAY

Aici se documentează participarea oamenilor în ecosistem, nu funcțiile tehnice ale platformei.

Subiecte posibile:

- contribuții;
- feedback și testare;
- facilitare;
- organizarea sesiunilor;
- Prestige;
- roluri;
- acces progresiv;
- guvernanță.

Prestige este diferit de Founder Skills, Credits și Equity.

Nu deschide guvernanța sau drepturile sensibile fără reguli clare, responsabilitate și protecția identității proiectului.
