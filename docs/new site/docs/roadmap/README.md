# Roadmap și stare curentă

Acest folder răspunde la:

- ce există acum;
- ce este validat;
- ce lipsește;
- ce urmează.

În prezent conține:

- `current-assets.md` — inventarul amplu al proiectului;
- `educational-program-work-order.md` — ordinea de lucru pentru dezvoltarea programului educațional și punctul de reluare.

Inventarul nu este roadmap săptămânal și nu este sursa canonică pentru formule sau definiții dacă există un document dedicat.

Documentele de focus și roadmap vor fi create numai când sunt necesare și aprobate.
