# Formate educaționale

Aici vor fi documentate formatele prin care este livrat programul.

Exemple aflate în lucru:

- Joc + Debrief;
- Founder Round;
- Competiție / Campionat.

Fiecare format trebuie să descrie scopul, publicul, durata, condițiile de participare, rolul facilitatorului și relația cu jocurile.

Nu transforma o experiență informală într-un format oficial fără documentare și testare.
