# Produsele EZPLAY

Acest folder conține documentația produselor livrate sau aflate în dezvoltare.

Cele două familii principale sunt:

- `educational-program/` — experiențele educaționale;
- `games/` — jocurile și simulările folosite de ecosistem.

Un produs trebuie separat de metodă: metoda poate fi comună, iar produsul definește publicul, experiența, componentele și modul de livrare.

Un folder existent nu înseamnă că produsul este validat.
