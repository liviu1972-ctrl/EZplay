# Datele cărților

Aici intră sursele structurate ale cărților: CSV, JSON sau alte formate versionabile.

Fiecare carte trebuie să aibă un identificator stabil care se leagă de:

- valorile economice;
- efecte;
- tip;
- limbă;
- imagine;
- starea versiunii.

Baza Supabase poate fi sursa operațională, dar repository-ul are nevoie de exporturi controlate și documentate.
