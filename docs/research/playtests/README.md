# Playtest-uri

Aici se documentează testele jocurilor și experiențelor.

Un raport util include:

- data și versiunea;
- participanții și contextul;
- configurația;
- ce s-a observat;
- probleme;
- ipoteze;
- schimbări recomandate;
- ce trebuie retestat.

Protejează identitatea și datele minorilor.

## Documente

- [`historical-session-evidence.md`](historical-session-evidence.md) — sinteză retrospectivă a ceea ce poate și nu poate fi afirmat pe baza inventarului actual;
- [`report-template.md`](report-template.md) — șablonul obligatoriu pentru sesiunile noi.

Rapoartele viitoare se leagă de versiunea jocului, de întrebarea testului și de decizia pe care o pot informa. Citatele, fotografiile, materialele video, numele și logo-urile necesită o intrare separată în registrul de permisiuni.
