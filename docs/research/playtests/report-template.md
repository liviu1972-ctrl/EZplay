# Șablon pentru raport de playtest sau sesiune EZPLAY

## Regula de utilizare

Se duplică acest fișier pentru fiecare sesiune. Numele recomandat este:

```text
YYYY-MM-DD-tip-sesiune-versiune-joc.md
```

Raportul nu include nume, date de contact sau alte date personale ale participanților. Evidența acordurilor se păstrează separat, cu acces limitat, iar raportul folosește numai ID-uri anonime dacă sunt necesare.

## Protocol

1. Ce informații primesc participanții înainte de început?
2. Ce face facilitatorul și ce nu face?
3. Ce momente sau decizii sunt urmărite?
4. Ce întrebări sunt puse identic tuturor?
5. Ce schimbare obligă oprirea sau adaptarea sesiunii?

## Feedbackul participanților

Se folosesc rezumate anonime. Un citat exact necesită permisiune și legătură cu intrarea corespunzătoare din registrul de permisiuni.

## Probleme și incidente

- reguli neclare;
- blocaje de accesibilitate;
- disconfort sau conflict;
- problemă de siguranță;
- problemă tehnică;
- date colectate accidental;
- alt incident.

Pentru un incident care implică un minor sau date personale se urmează procedura separată aprobată; raportul de produs nu devine depozit de date sensibile.
